환경 변수 편집기
================

열기
----

도구 › 시스템 도구 › 환경 변수를 선택하거나 Ctrl+Alt+E를 누릅니다.
Ctrl+G 폴더 즐겨찾기와 Alt+F1/Alt+F2 위치 메뉴에서도 열 수 있습니다.
프로세스 보기의 바로 가기 메뉴에서 환경을 열면 반대 패널에서 해당 프로세스를 비교합니다.

Ctrl+Alt+E의 글로벌 등록은 기본으로 꺼져 있습니다.
글로벌로 켜면 AltGr+E로 입력하는 문자와 충돌할 수 있습니다.
설정 › 키보드 › 환경 변수 보기에서 보기 명령과 기능 키 막대를 바꿉니다.

범위와 값
---------

사용자와 시스템 범위에는 레지스트리에 저장된 원문이 표시됩니다.
REG_SZ와 REG_EXPAND_SZ 형식은 저장할 때 보존됩니다.
시스템 변수 변경은 관리자 도우미가 수행하며 사용자 변수는 HC를 실행한 계정에 적용합니다.

적용 결과는 Windows 기본값, 시스템 문자열, 시스템 확장 문자열, 계정 값,
사용자 문자열, 사용자 확장 문자열, 별도 이어 붙이기의 순서로 계산합니다.
Path·LibPath·Os2LibPath는 시스템 값 뒤에 사용자 값을 이어 붙입니다.
같은 단계에서 아직 정해지지 않은 참조를 임의로 반복 확장하지 않습니다.

HyperCommander 범위에는 현재 HC의 환경이, 프로세스 비교에는 선택한 프로그램의 환경이 표시됩니다.
프로세스 환경은 읽기 전용입니다. PID가 같아도 생성 시각이 다르면 같은 프로그램으로 취급하지 않습니다.
접근할 수 없는 경우 바로 가기 메뉴에서 관리자 도우미로 다시 읽을 수 있습니다.
옛 환경 찾기는 셸·편집기·빌드 도구를 제한된 시간 안에서 조회하며 자동으로 UAC를 요청하지 않습니다.
프로그램 자체가 추가한 변수도 차이에 포함될 수 있습니다.

편집과 저장
-----------

F4 또는 Ctrl+Q로 반대 패널의 상세 보기를 엽니다.
설명·값·적용·출처 탭에서 뜻, 원문, 확장 순서와 저장 위치를 확인합니다.
폴더 값, %변수% 참조, Path 목록, PATHEXT 순서, 알려진 선택 값, 비밀 값에 맞는 입력기를 사용합니다.

저장할 때 변경 미리 보기를 확인합니다. 외부 프로그램이 원래 값을 바꾸었으면 덮어쓰지 않고 충돌을 알립니다.
저장에 실패해도 편집 초안은 유지됩니다.
Path 항목은 위·아래 키로 고르고 Ctrl+위·아래, 버튼 또는 끌어 놓기로 순서를 옮깁니다.
빈 항목과 마지막 구분자는 원문에 남으므로 의도한 값인지 확인합니다.

저장 후 Windows에 환경 변경을 알리고 HC의 환경을 갱신합니다.
이미 실행 중인 다른 프로그램의 환경은 바꾸지 않습니다.
새 환경을 쓰려면 해당 프로그램을 다시 시작해야 할 수 있습니다.
HC에서 새로 시작하는 프로그램은 갱신된 환경을 받습니다.

점검과 명령 찾기
---------------

Path와 PSModulePath 점검은 없는 폴더, 중복, 앞 항목에 가려짐, 정의되지 않은 참조,
확장 순서, 따옴표, 빈 항목, 일반 사용자가 쓸 수 있는 폴더, setx로 합친 흔적을 구분합니다.
접근 거부나 시간 초과는 폴더가 없다는 뜻이 아닙니다.
진단만으로 원문을 자동 수정하지 않습니다.

Ctrl+F의 명령 찾기는 선택한 환경의 Path와 PATHEXT를 사용합니다.
현재 폴더를 포함할지는 직접 선택합니다.
셸 함수·별칭과 App Paths는 검색에 포함하지 않으며 명령을 실행하지 않습니다.
후보를 선택하여 파일 위치로 이동할 수 있습니다.

변경 기록과 프로필
------------------

변경 기록에서 저장 전후 값과 적용 상태를 확인하고 Ctrl+Z/Ctrl+Y로 되돌리기·다시 실행합니다.
복구도 현재 값이 예상한 값과 같은지 확인합니다.
충돌이나 복구 확인이 필요한 기록을 무시하고 다른 프로그램의 변경을 덮어쓰지 않습니다.
일반 백업은 .reg로, 비밀을 포함한 복구 자료는 현재 사용자에게 묶인 암호화 자료로 보관합니다.

프로필에는 사용자 변수 묶음을 저장합니다.
켜기 전에 미리 보기를 확인하며, 변수 이름이 겹치는 프로필은 동시에 켤 수 없습니다.
끄면 적용 전 값으로 복구합니다. 프로필이 켜진 동안 원래 값이 외부에서 바뀌었다면 충돌을 확인해야 합니다.
켜진 프로필의 값을 편집할 때도 변경 미리 보기와 원래 값 대조를 거칩니다.

가져오기·내보내기는 .reg, JSON, .env 형식을 지원하며 환경 변수 범위에 한정됩니다.
민감한 값은 일반 내보내기에서 제외되거나 가려집니다.
TOKEN·KEY·SECRET·PASSWORD를 포함한 이름과 그 값을 참조하는 변수는 기본으로 가립니다.
가린 값을 누르는 동안만 볼 수 있으며, 일반 복사는 가린 표시를 복사합니다.
변수의 바로 가기 메뉴에서 자동 가림 예외를 명시적으로 설정할 수 있습니다.
표시 예외를 설정해도 비밀 백업의 암호화 규칙은 유지됩니다.
