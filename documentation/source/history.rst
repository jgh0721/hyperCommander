HyperCommander 변경 이력
========================================

.. 수정 사항은 '다음 버전' 섹션에 기록한다. 릴리즈 버전이 확정되면 해당
   섹션 제목을 버전과 날짜로 교체하고, 그 위에 새 '다음 버전' 섹션을 생성한다.

다음 버전
----------------------------------------

* 작업 관리자에서 선택 작업·대기열·전체 작업·이력 제어를 구분하고, 대상 경로와 항목 수를 버튼 근처에 표시. 큰 글꼴에서는 제어 영역을 스크롤하여 모든 버튼 사용 가능.
* '모두 정지'를 일시 정지 요청으로 명확히 표시. 일시 정지 요청·재개·취소 후 정리·실패 항목 재시도·중단 기록을 구분하고, 이름 변경 이력의 상태와 복구 버튼을 자동 갱신.
* 삭제 그래프와 속도를 초당 삭제 파일 수로 표시하고, 작업 관리자에서 바이트 전송 속도와 분리하여 집계.
* 삭제 목록 확인 중 움직이는 불확정 진행 막대와 확인한 항목·파일 수를 표시. 전체 집계 전에는 총개수를 확정하지 않고 일시 정지·취소 지원.
* 설정 → 파일 작업 → 삭제에 '파일 목록을 확인하는 중에도 삭제 시작' 옵션 추가(기본값 켜짐). 영구 삭제는 확인한 파일부터 처리하고, 휴지통 삭제는 폴더 복원 구조를 유지하도록 선택 항목 단위로 확인 후 처리.
* 파일 그룹 조건에 파일명 정규화를 추가. NFC 기준으로 자소가 분리된 NFD·혼합 이름을 구분하여 색상·글꼴 규칙 적용.
* Qtitan 통합 회귀 테스트와 소스 검증 도구를 ``tests/qtitanIntegration``으로 정리.
* 탐색 설정에 빠른 찾기 탭 추가. 활성화 방식, 검색 범위, 시작·포함·끝 일치와 한글 IME 입력 지원.
* 빠른 찾기에 필터링·커서 이동(기본값) 추가. 위·아래 화살표로 일치 항목 이동 및 Ctrl+S로 표시 방식 전환 지원.
* 파일 목록·Everything 검색의 일치 부분 강조 표시 및 기본 켜짐 설정 추가.
* 빠른 찾기·Ctrl+F·클릭으로 상단 검색창에 들어간 뒤 Esc를 누르면 검색어와 필터를 초기화하고 현재 파일 목록 패널로 키보드 포커스 복귀.
* 대량 파일 목록의 페이지 구분을 제거하여 전체 항목을 연속 스크롤·검색·선택하도록 개선.
* 글꼴 크기와 화면 배율에 따라 목록 포커스 틀의 일부 변이 잘리는 문제 수정.
* 커서 색상 반전 상태에서도 모든 컬럼의 파일 그룹 글자색을 유지하고, 상단 파일 작업·설정·업데이트 버튼 높이를 통일.
* 파일 색상 규칙의 글자색·굵기를 이름·확장자·크기·날짜·속성 등 모든 목록 컬럼에 적용.
* 도움말 메뉴가 다른 메뉴와 겹쳐 클릭을 가로막는 문제 수정.
* 업데이트 재시작 시 종료한 프로그램의 상태 확인과 PID 재사용 처리 보완.
* 업데이트 실패 기록 보존 및 파일 교체 실패 시 대상 경로·Windows 오류 코드 표시 보강.

v2026.10.18.4 (2026-10-18)
----------------------------------------

* HyperViewer 탭에 임시 사본 이름 대신 원본 파일명을 표시하도록 수정.
* HyperViewer·HyperEditor의 가로·세로 스크롤바 테마와 주변 렌더링 오류 수정.
* 문서 공통 도구모음·메뉴 아이콘 표시 및 테마 변경 시 아이콘 색상 갱신.
* 독립 HyperViewer 창을 전경으로 전환한 직후 텍스트 입력 포커스 복원.
* 폴더 즐겨찾기 메뉴를 각 패널의 컬럼 헤더 바로 아래 왼쪽에 표시하도록 수정.
* 탐색 설정에 새로고침 탭 추가. 파일시스템 변경 통지 옵션과 통지 미지원 위치의 주기 새로고침 설정을 분리하고, 주기 새로고침 기본값을 꺼짐으로 변경.

배포 파일
~~~~~~~~~~~~~~~~~~~~

* ``HyperCommander-2026.10.18.4-windows-x64-portable.zip``: Windows x64 실행 패키지.
* ``HyperCommander-2026.10.18.4-windows-x64-symbols.zip``: 해당 빌드의 디버그 심볼.
* ``update-manifest.json`` 및 ``update-manifest.cat``: 자동 업데이트 정보와 서명된 카탈로그.

* 업데이트 및 로컬 설치 시 사용자 설정과 추가 플러그인 보존.

* 파일 이동 후 원본 삭제 재시도와 읽기 전용 파일 처리 보완.
* 클릭 이름 변경의 오동작 방지 및 사용 설정 추가.
