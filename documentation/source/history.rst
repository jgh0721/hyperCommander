HyperCommander 변경 이력
========================================

.. 수정 사항은 '다음 버전' 섹션에 기록한다. 릴리즈 버전이 확정되면 해당
   섹션 제목을 버전과 날짜로 교체하고, 그 위에 새 '다음 버전' 섹션을 생성한다.

다음 버전
----------------------------------------

* HyperCompare 비교 화면의 방향 화살표를 대상 문서 즉시 반영으로 변경하고 원본별 저장·Undo를 지원한다.

* HyperCompare 블록 제거 선택의 JSON 보고와 기본 비교 엔진 버전 표시를 수정한다.

* HyperCompare RESULT 저장 단계의 복구 기록과 명령행 조회·미리보기·백업 복원을 지원한다.

* HyperCompare BASE·RESULT를 포함한 전체 패널 정렬과 편집 후 비동기 재정렬을 지원한다.

* HyperCompare 3way 자동 병합 구간의 개별 재선택과 결정 계획 보존 지원

* HyperCompare 청크별 RESULT 적용·제거·결합 버튼과 대응 영역 연결선 추가

* HyperCompare 파일별 인코딩 지정, BOM 차이 표시 및 내용 기준 동등성 판정 추가

* HyperCompare 기존 GUI 프로세스에 요청별 창을 전달하고 개별 완료 코드·대기 취소·연결 단절 시 RESULT 보존 지원

* HyperCompare UNC 디렉터리 병합의 공유 루트 검증 수정, 매핑·UNC 별칭의 입력/출력 중첩 보호 및 네트워크 통합 시험 추가

* HyperCompare 공통 앞뒤 구간과 불일치 줄 집합의 정확한 단축 경로를 추가해 대량 변경의 메모리 실패를 줄였다.

* HyperCompare 배치 JSON·동시 작업 상한·경로 충돌 사전 검사·NDJSON 및 전송 중단 처리를 추가했다.

* HyperCompare 버전형 JSON 요청 파일, 역할별 인코딩 및 요청 파일 덮어쓰기 방지를 추가했다.

* HyperCompare DOCX 본문 문단 비교와 내부 구성 파일 비교를 격리 worker에 추가하고 분석 범위를 명시했다.

* HyperCompare ZIP 내부 항목의 경로·CRC·내용 해시 비교, 읽기 전용 목록 화면 및 격리 압축 해제를 추가했다.

* HyperCompare 격리 PNG 2way 비교 어댑터 추가. 원본 RGBA8 픽셀·파일 바이트 차이를 구분하고 변경 영역 Location, 원본 해상도 확대, sRGB 표시, Light/Dark 화면 및 실제 입력 probe를 제공한다.

* HyperCompare 파서 IPC를 버전형 공통 워커로 분리하고 요청 ID·엔진·내용 해시를 검증한다. 같은 로그온 세션의 GUI·CLI 워커를 두 개로 제한하며 비정상 종료 슬롯을 회수한다.

* HyperCompare 텍스트·디렉터리·함수 분석 엔진의 버전·decoder·writer·view·Location schema와 비교/병합 기능을 분리한 registry 추가. 명령행 probe로 입력 형식·전체 텍스트 디코딩·한도·3파일 지원 여부와 미지원 사유를 조회한다.

* HyperCompare C/C++ 함수 이름·scope·서명 대응과 상대 순서 이동·수정 분석 추가. 일반 3파일·BASE 비교 쌍의 함수 변경 탭, 원본 함수 선택·탐색, semantic auto/off 및 JSON 분석 범위·모호성 보고 지원.

* HyperCompare Tree-sitter 버전을 고정하고 C/C++ 함수 범위·토큰 해시를 별도 프로세스에서 추출한다. 워커의 메모리·시간·출력 크기를 제한하고 패키지에 라이선스를 포함한다.

* HyperCompare 디렉터리 BASE 비교의 비충돌 텍스트 변경 자동 병합 추가. LEFT 인코딩·BOM·줄 끝 유지, 파일별 분석 한도와 충돌/바이너리 fallback, 실행 전 재계산·내용 검증 및 계획 schema 1 호환 지원.

* HyperCompare 디렉터리 병합 계획 GUI 추가. 출력·교체·mirror 설정, LEFT/RIGHT/BASE·제외 선택, 새 계획 저장·적용·재개 지원. 저장 후 외부 계획 변경과 설정·선택 변경 시 적용 차단, 작업을 백그라운드에서 수행하고 취소 지원.

* HyperCompare 디렉터리 결과를 가상 테이블로 표시하고 경로 검색·차이/충돌 필터·F7 탐색·파일 비교 열기 추가. BASE 관계와 비교 수준 표시, 디렉터리 모드의 불필요한 텍스트 병합 명령 숨김 및 실제 충돌 수 표시.

* HyperCompare 디렉터리 계획의 입력·대상 전체 사전 검증, 검증된 스트리밍 복사, 명시적 삭제 승인, 파일별 영속 저널 및 중단 재개 추가. 완료 후 기록 손실은 내용 검증으로 판정하며 보존 대상 자식·오래된 입력·변경된 출력·잘못된 계획은 실행 거부.

* HyperCompare 디렉터리 2way 선택 및 BASE 3way 관계 기반 병합 계획 JSON 내보내기 추가. 입력·대상의 revision과 SHA-256, 파일별 선택 기록, 출력 추가 파일 기본 보존 및 mirror 계획, 입력·출력·계획 경로 중첩 거부.

* HyperCompare 디렉터리 비교에 BASE 기반 3way 추가·삭제·수정·충돌 분류와 포함/제외 필터, byte 내용/메타데이터 비교 수준 추가. 비교 후 목록·revision 재검증으로 입력 변경을 검출하고 JSON에 비교 수준과 필터 적용 여부 표시.

* HyperCompare 일반 3파일 비교에 FILE1/2·FILE1/3·FILE2/3 선택 추가. 선택한 쌍의 차이 목록·줄/문자 강조·표시 여백 정렬·스크롤·개요·F7 탐색을 함께 전환하고 제외된 원본의 기존 강조·여백 제거. 입력 snapshot을 재사용하여 전환 시 파일 재읽기 없이 선택·Undo를 보존하며, 재비교로 새 입력을 반영. BASE 병합·headless 비교 결과와 저장 계약 유지.

* HyperCompare 첫 두 원본에 차이 개요 막대 추가. 삽입·삭제·변경·대응 여백과 현재 화면 범위를 표시하고 클릭·드래그·키보드 이동, 표시 줄 정렬·스크롤 동기화·Light/Dark·보기 설정 지원. 표시 배열을 화면 높이에 맞춰 제한하며 재비교 후 갱신과 병합 재비교 실패 시 기존 표시 유지, 원본 선택·병합 결과·Undo·저장 내용 보존.

* HyperCompare 첫 두 원본 패널에 변경 줄 내부의 Unicode 문자 차이 강조 추가. Light/Dark와 보기 설정, 검색 선택·구문 강조의 동시 표시, 재비교 후 강조 갱신 지원. 긴 줄·반복 입력에는 계산량·표시 범위 상한을 적용하고 생략 안내와 줄 단위 표시를 유지하며 병합 결과·Undo·저장 내용은 보존.

* HyperCompare에 원본·BASE·RESULT 패널별 문자열 검색 추가. Ctrl+F, F3/Shift+F3, 대소문자·단어 단위 옵션, 순환 검색과 Esc 닫기 지원. Unicode와 표시 여백을 구분하여 검색하고 범위를 나누어 처리하며 검색어·대상·본문 변경과 재비교 시 중단. 검색으로 병합 내용·해결 상태·Undo를 변경하지 않으며 Light/Dark 선택 영역 가독성 개선.

* HyperCompare 두 원본의 표시 줄 정렬 추가. 삽입·삭제·길이가 다른 변경에 문서 밖 표시 여백을 배치하고 BOF·EOF·빈 파일·마지막 개행 경계를 지원. 정렬 여백을 복사·저장·Undo에 포함하지 않으며 정렬 전환, 동일 표시 행 스크롤과 차이 탐색, 재비교 후 여백 갱신 지원. BASE·RESULT 포함 전체 pane 정렬은 후속 구현 대상.

* HyperCompare의 두 원본 패널에 대응 줄 기반 양방향 스크롤과 가로 위치 동기화 추가. 삽입·삭제·빈 파일·EOF 경계를 처리하고 동기화 설정 유지. F7/Shift+F7 차이 순환 탐색, 단일 차이 재탐색과 재비교 후 매핑 갱신 지원. 원본·RESULT 내용과 Undo를 보존하며 BASE·RESULT의 전체 표시 정렬은 후속 구현 대상.

* HyperCompare 병합 작업 저장·불러오기 추가. 전체 RESULT와 블록별 해결·위치·재검토 상태를 ``.hcmerge`` 파일로 보존하고 복원을 한 번의 Undo/Redo로 처리. 원본·정책 불일치, 손상된 작업 파일, 외부에서 수정한 작업 파일의 덮어쓰기를 거부하며 작업 저장과 결과 파일 저장 상태를 구분.

* 독립 HyperCompare 개발 빌드 추가. 파일 2개·3개 비교, BASE 기반 3way 병합과 전체 방향 선택 2way 병합, 디렉터리 내용 비교, Scintilla 구문 강조, Watercolor Light/Dark와 UI·목록·본문 글꼴 설정 지원. ``-file1``·``-file2`` 명령행 및 별도 콘솔 실행 파일 제공. 디렉터리 병합·함수 이동 분석은 후속 구현 대상.
* HyperCompare RESULT에 블록별 LEFT·RIGHT·BASE·양쪽 순서·수동 해결 선택 추가. 텍스트와 해결 상태의 Undo/Redo, 앞선 편집에 따른 뒤쪽 블록 위치 갱신, 미해결 저장 방지 지원. 블록 경계를 넘는 수동 편집은 자동 적용을 제한하고 전체 결과 재검토 가능.
* HyperCompare 재비교 시 RESULT와 텍스트 Undo 보존. 동일 입력은 해결 상태를 유지하고, 변경 입력은 내용·문맥·순서가 대응되는 블록 결정만 유지하며 전체 결과 재검토 후 저장. 읽기 실패·취소 시 기존 세션 유지 및 외부 출력 파일 변경 감시 기준 보존.
* HyperCompare 명령행에 ``-planout``·``-decisions`` 추가. 입력·정책·블록 해시에 묶인 2way/3way 결정 계획의 내보내기와 LEFT·RIGHT·BASE·양쪽 순서·수동 내용 적용 지원. 미해결 결과 저장 방지, 오래된 계획·중복 JSON 키·경로 별칭 거부 및 계획 파일 변경 재검증 적용.

* 폴더 진입 후 파일 그룹 색상 조건을 작업 스레드에서 평가하고 폴더 용량은 목록 조회와 별도 작업 풀에서 계산한 뒤 제한된 묶음으로 반영. 아이콘·색상 갱신의 불필요한 레이아웃 재계산과 용량 갱신의 이름 컬럼 무효화를 줄여 백그라운드 계산 중에도 커서·선택·폴더 이동 유지.

* 설정에 비밀번호 관리 추가. 저장된 압축 비밀번호의 추가·편집·삭제·자동 시도와 작업·실행 단위 기억을 지원하고, 입력창에 저장 항목 선택·표시 전환·관리 화면 연결 추가. 저장소는 Windows 계정으로 보호하며 마스터 비밀번호를 선택적으로 설정·변경·해제하고 잠금 가능. 내장 7-Zip과 ALZ·EGG의 잘못된 암호 재시도·취소 처리 연결.

* 파일 복사에서 Windows 복사 API와 ReFS 블록 복제를 목적지 검증·공개 절차에 연결. 작은 파일의 읽기 버퍼와 작업 전달 비용을 줄이고 내용 검증·속도 제한·복구 기록이 필요한 경우 기존 전송 경로 유지.

* WCX 압축 해제에서 선택 항목을 한 번에 목적지 볼륨에 추출하고 내용을 다시 복사하지 않고 공개. 내장 7-Zip은 전용 SDK의 목적지 스트리밍을 유지. ISO 플러그인의 파일 입력을 Win32 readAt으로 개선하고 원본 교체·추출 오류·취소 시 기존 목적지 보존.

* 목록·트리·표의 점선 포커스 테두리 제거. 키보드 이동과 선택 강조는 유지하고 관리자 권한 이력·권한 진단 표의 세로 헤더 숨김.

* 내장 7-Zip에 ZIPX 읽기 지원 추가. 단일·AES ZIPX와 .zxNN 분할 세트의 탐색·검사·압축 해제를 지원하며 원본 이름을 유지. ZIPX 생성·수정은 읽기 전용으로 제한.
* ZIPX·ZIP·7z·RAR 분할 압축의 첫 번째·중간 조각에서도 전체 세트로 진입. 탐색·직접 해제·탭 복원에 공통 조각 판정을 적용하며 누락 기준 파일과 모호한 세트·무관한 조각을 거부.

* 파일·폴더 아이콘을 패널·탭 공유 캐시로 관리하고 화면 주변 항목부터 비동기 획득. 자동완성 아이콘 재사용, 변경 감지·만료 재검증, F5 일반 새로고침과 Ctrl+F5 아이콘 강제 갱신 지원. EXE 리소스 변경과 폴더 사용자 지정·오버레이 반영.

* 이미지 편집 도구모음은 HyperEditor에서 기본 표시하고 HyperViewer·F3에서는 숨김. 이미지 도구모음 첫 줄의 편집 버튼으로 표시·숨기기 전환.

* 파일 패널 2줄 모드에서 크기 컬럼에 아이콘 들여쓰기와 실제 표시 문자열의 너비를 반영해 값·단위 잘림 방지. 1줄 모드의 크기·날짜·속성 너비에도 셀 여백과 표시 형식 반영.
