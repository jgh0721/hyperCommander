HyperCommander 변경 이력
========================================

.. 수정 사항은 '다음 버전' 섹션에 기록한다. 릴리즈 버전이 확정되면 해당
   섹션 제목을 버전과 날짜로 교체하고, 그 위에 새 '다음 버전' 섹션을 생성한다.

다음 버전
----------------------------------------

* 도움말 메뉴가 다른 메뉴와 겹쳐 클릭을 가로막는 문제 수정.
* 업데이트 재시작 시 종료한 프로그램의 상태 확인과 PID 재사용 처리 보완.
* 업데이트 실패 기록 보존 및 파일 교체 실패 시 대상 경로·Windows 오류 코드 표시 보강.

v2026.10.18.4 (2026-10-18)
----------------------------------------

* HyperViewer 탭에 임시 사본 이름 대신 원본 파일명을 표시하도록 수정.
* HyperViewer·HyperEditor의 가로·세로 스크롤바 테마와 주변 렌더링 오류 수정.
* 문서 공통 도구모음·메뉴 아이콘 표시 및 테마 변경 시 아이콘 색상 갱신.
* 독립 HyperViewer 창을 전경으로 전환한 직후 텍스트 입력 포커스 복원.
* 폴더 즐겨찾기 메뉴를 각 패널의 컬럼 헤더 바로 아래 왼쪽에 표시하도록 수정.
* 탐색 설정에 새로고침 탭 추가. 파일시스템 변경 통지 옵션과 통지 미지원 위치의 주기 새로고침 설정을 분리하고, 주기 새로고침 기본값을 꺼짐으로 변경.

배포 파일
~~~~~~~~~~~~~~~~~~~~

* ``HyperCommander-2026.10.18.4-windows-x64-portable.zip``: Windows x64 실행 패키지.
* ``HyperCommander-2026.10.18.4-windows-x64-symbols.zip``: 해당 빌드의 디버그 심볼.
* ``update-manifest.json`` 및 ``update-manifest.cat``: 자동 업데이트 정보와 서명된 카탈로그.

v2026.10.18.3 (2026-10-18)
----------------------------------------

* 서명된 Portable ZIP 배포와 자동 업데이트 추가.
* 업데이트 파일의 서명·해시 검증과 실패 시 복구 지원.
* 업데이트 및 로컬 설치 시 사용자 설정과 추가 플러그인 보존.
* HyperViewer·HyperEditor 문서 열기 구조와 텍스트 편집 설정 통합.
* 파일 이동 후 원본 삭제 재시도와 읽기 전용 파일 처리 보완.
* 클릭 이름 변경의 오동작 방지 및 사용 설정 추가.
