HyperCommander 변경 이력
========================================

v2026.10.18.3 (2026-10-18)
----------------------------------------

* 서명된 Portable ZIP 배포와 자동 업데이트 추가.
* 업데이트 파일의 서명·해시 검증과 실패 시 복구 지원.
* 업데이트 및 로컬 설치 시 사용자 설정과 추가 플러그인 보존.
* HyperViewer·HyperEditor 문서 열기 구조와 텍스트 편집 설정 통합.
* HyperViewer 탭의 원본 파일명 표시, 문서 스크롤바 테마와 주변 잔상, 공통 도구모음·메뉴 아이콘 표시 수정.
* 파일 이동 후 원본 삭제 재시도와 읽기 전용 파일 처리 보완.
* 클릭 이름 변경의 오동작 방지 및 사용 설정 추가.
* 폴더 즐겨찾기 메뉴를 각 패널의 컬럼 헤더 바로 아래 왼쪽에 표시하도록 수정.
* 탐색 설정에 새로고침 탭 추가. 파일시스템 변경 통지 옵션과 통지 미지원 위치의 주기 새로고침 설정을 분리하고, 주기 새로고침 기본값을 꺼짐으로 변경.

배포 파일
~~~~~~~~~~~~~~~~~~~~

* ``HyperCommander-2026.10.18.3-windows-x64-portable.zip``: Windows x64 실행 패키지.
* ``HyperCommander-2026.10.18.3-windows-x64-symbols.zip``: 해당 빌드의 디버그 심볼.
* ``update-manifest.json`` 및 ``update-manifest.cat``: 자동 업데이트 정보와 서명된 카탈로그.
