EPUB 리더·편집기 사용 안내
================================================================================

HyperViewer와 HyperEditor는 EPUB을 읽기 전용 리더 모드로 연다.
도구 모음의 ``편집`` 버튼을 누르면 HyperEditor의 소스 편집 모드로 전환한다.
HyperViewer에서 누른 경우에는 읽기 위치와 앱 테마를 전달하여 HyperEditor를 연다.
본문 표시에는 QtWebEngine과 EPUB.js 0.3.93을 사용한다.
앱 도구 모음·패널·대화상자에는 기존 Watercolor 테마를 적용한다.
Readium Web은 개발 비교 대상으로 남아 있으며 제품의 기본 엔진은 EPUB.js이다.

읽기 조작
--------------------------------------------------------------------------------

* ``이전`` / ``다음`` 및 PgUp / PgDn: 한 화면 이동. 세로 스크롤에서는
  같은 장 안에서 화면 높이의 약 90%를 이동하고 장 끝에서 다음 장으로 이동한다.
  숫자 키패드 PgUp / PgDn도 지원한다. 검색·메모·설정 입력에 포커스가 있으면
  해당 입력을 우선하며, 본문으로 포커스를 돌린 뒤 페이지 키를 사용한다.
* ``목차`` / ``책갈피`` / ``검색`` / ``형광펜·메모`` / ``Aa · 읽기 설정``:
  해당 패널을 열고 같은 버튼으로 닫는다. 목차 항목은 연결된 장·앵커로 이동한다.
* 세로 스크롤과 가로 페이지를 선택할 수 있다. 가로쓰기는 자동 / 1단 / 2단을
  지원한다. 폭이 좁으면 한 단으로 표시하며, 세로쓰기와 고정 페이지는 한 단이다.
  세로쓰기의 스크롤 방향은 본문의 쓰기 방향을 따른다.
* 이미지 확대는 표시용이며 원본을 변경하지 않는다. 내장 글꼴과 이미지 준비 후
  새 화면을 표시한다. 장 경계와 창 크기 변경에서도 마지막 정상 화면을 유지한다.

읽기 설정
--------------------------------------------------------------------------------

설정의 EPUB 페이지 또는 리더의 읽기 설정 패널에서 기본값과 책별 값을 지정한다.
글꼴·굵기·크기, 자간·단어 간격, 행간, 문단 앞·뒤 간격, 들여쓰기, 정렬,
여백과 본문 폭을 각각 조정할 수 있다. 출판사 서식을 선택하면 본문 서식을 유지한다.

라이트·다크·세피아·연녹색·앱 테마 배경, 사용자 색상과 배경 이미지를 지원한다.
배경 이미지의 배치와 불투명도를 조정할 수 있다. CSS 재설정은 표시용 제한 문법을
검사한 후 적용하며 네트워크 요청이나 출판물 스크립트를 허용하지 않는다.
고정 레이아웃 페이지는 출판사의 글꼴·배치·색상을 유지하고 종이 바탕을 사용한다.

이름 있는 프로필에는 서식·CSS·관리되는 배경 이미지를 보관한다.
프로필 JSON을 가져온 후 미리보기를 확인하고 ``적용``으로 현재 범위에 저장한다.
같은 이름을 덮어쓸 때에는 덮어쓰기 선택이 필요하다. 읽기 위치·책갈피·메모와
개인정보 설정은 서식 프로필에 포함하지 않는다. 프로필은 32개까지 보관한다.

형광펜·메모와 판본 연결
--------------------------------------------------------------------------------

본문 문장을 선택하고 색상과 메모를 지정한 뒤 ``선택한 본문에 형광펜·메모 추가``를
누른다. 기존 메모의 내용과 색상은 ``선택 메모 수정``으로 저장한다.
메모는 EPUB 원본과 별도인 독서 기록에 보관하며, 책당 32개·인용 512자·메모 2048자와
기록 용량 제한을 적용한다. 입력 중인 미저장 메모는 수정 버튼을 눌러야 보관된다.

메모 JSON을 다른 판본에 가져오면 인용과 앞뒤 문맥으로 위치를 검색한다.
일치 위치가 여러 곳이거나 검색 한도에 도달하면 미연결 상태로 보관한다.
미연결 항목을 선택하고 올바른 본문을 선택한 뒤 다시 연결할 수 있다.
원본 파일의 해시가 다른 판본에 이전 CFI를 그대로 적용하지 않는다.
동일 메모를 다른 창에서 수정한 경우에는 기존 파일과 현재 변경을 보존하며
내보내기 또는 변경 취소·다시 불러오기로 정리한다.
읽기 위치를 보관하지 않는 모드에서도 명시적으로 추가한 메모와 책갈피는 보관한다.
편집 미리보기에서는 영구 메모와 책갈피를 추가하지 않는다.

편집·검사·복구
--------------------------------------------------------------------------------

DRM 없는 파일의 XHTML·CSS·OPF 메타데이터, 이미지와 목차·읽기 순서를 편집한다.
이미지 추가·삭제·경로 변경과 표지 지정, PNG/JPEG 변환, 같은 형식의
PNG/JPEG/GIF/WebP 교체를 지원한다. 참조가 남은 리소스의 삭제는 중단한다.
소스와 미리보기의 장 연결, 실시간 갱신, 구조 작업 실행 취소를 지원한다.

저장은 ``검증 후 다른 이름으로 저장``으로 진행한다. 원본과 원본의 하드링크에는
덮어쓰지 않는다. 기본 구조·XML·CSS 괄호 검사를 수행하며, 설정에 Java와 EPUBCheck
JAR를 지정하면 EPUBCheck도 실행한다. 기본 검사는 규격 적합성 인증을 대신하지 않는다.
필수 EPUBCheck 실패 또는 검사 중 내용 변경이 있으면 저장을 중단한다.
저장 뒤에는 선택 리소스·커서·선택 범위와 편집 포커스를 유지한다.

자동 복구가 켜져 있으면 편집 초안과 읽기 위치를 별도 보관한다.
비정상 종료 뒤 파일 메뉴의 ``EPUB 편집 초안 복구`` 또는 편집 복구 목록에서
복원한다. 원본이 이동·변경된 경우에도 보관된 판본을 검사하며 사본 저장을 사용한다.
한국어 조합 중에는 수동 반영·검사와 수동 읽기 모드 전환을 보류하며,
자동 미리보기 교체가 입력 포커스를 바꾸지 않도록 조합 완료까지 대기한다.

지원 범위와 한도
--------------------------------------------------------------------------------

* Windows Qt 6.12 제품의 DRM 없는 EPUB 2.0 계열 및 EPUB 3 계열을 대상으로 한다.
  EPUB 3.3도 package의 version 값은 3.0을 사용하므로 버전 문자열만으로 완전한
  EPUB 3.3 적합성을 보장하지 않는다. 실제 지원은 아래 콘텐츠 범위를 따른다.
* 수동적 XHTML의 리플로우·고정·혼합 레이아웃, 이미지·내장 글꼴,
  세로쓰기·RTL·Ruby를 지원 범위로 검증한다. 고정 XHTML은 숫자 viewport가 필요하다.
  모바일 Android/iOS 앱 구현은 현재 Windows 제품의 지원 범위에 포함하지 않는다.
* DRM·암호화와 글꼴 난독화, 서명된 출판물, 활성 스크립트,
  SVG를 직접 읽기 순서에 넣은 출판물, ZIP64 등은 지원하지 않는다.
* 입력 64 MiB, ZIP 항목 4096개, 항목당 해제 16 MiB, 해제 합계 128 MiB,
  렌더러 스냅샷 32 MiB 등의 한도를 유지한다. 16 MiB를 넘는 내장 글꼴도
  오류 대상이며 글꼴을 임의로 제거하거나 축소하여 열지 않는다.
* 로컬·UNC에서 같은 파일을 반복 측정한 결과를 구분하여 검증한다.
  QSync·SMB 서버의 상태에 따라 최초 파일 취득 시간이 달라질 수 있다.
* DPI 배율 시험과 연결된 모니터의 화면 검증, 실제 한국어 조합 검증을 구분한다.
  다중 모니터 이동과 실제 스크린리더의 연속 독서 경험은 별도 수동 검수 항목이다.

개발 검증
--------------------------------------------------------------------------------

제품의 런타임 승인 기준은 네이티브에 내장된 독립 해시와 서명된 inventory이다.
``qualification-policy.json``은 검증 기록이며 실행 권한을 부여하지 않는다.
Python과 Node는 개발 검증 도구의 의존성이며 제품 실행에 필요하지 않다.
회귀 자료는 직접 작성한 EPUB과 읽기 전용으로 검사한 사용자 파일을 구분한다.
시험·설치 기록은 ``_build/epub-next`` 아래에 보관한다.
